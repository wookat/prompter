## 逐维理由

### 1. 视觉设计
- **A = 5**：橙色 + 灰白配色基本统一，输入框用深色圆角卡片有一定对比；但整体像上一代工具站——背景散落装饰性色块（左上/右侧/左下的橙灰条块）无功能意义，标题下大段居中长文段落密度高，底部 cookie 横幅占据显著空间，移动端 375 首屏几乎被占位图与 cookie 提示吃掉，现代感弱。
- **B = 9**：米色底 + 黑色大号衬线感标题「Read your script. Look at the camera.」+ 琥珀色主按钮，层次干净克制；左侧模拟编辑器窗口（macOS 红黄绿圆点、字数/时长统计条）与右侧控制面板卡片形成清晰的双栏构图；控件（滑杆、pill 按钮、文字色三选）视觉规范统一，是三者中最现代、最像精心设计的产品。
- **C = 8**：大字标题「Look confident on camera. Every time.」+ 右侧手机/平板/相机屏组合渲染图，营销质感强，五星评分头像、双商店徽章、二维码等元素专业；扣分点：首屏元素偏多略显拥挤（三块设备渲染图相互叠压、镜像文字截断），移动端标题占屏比例过大。
- **胜者：B**。

### 2. 信息层级
- **A = 5**：优点是把「脚本输入框 + Start 按钮」直接放在首屏，任务导向明确；但标题区被两大块占位内容与长段说明文字推挤，「Start new prompter / Start old prompter」双按钮并列却未解释差异，造成选择歧义；移动端 375 首屏只见占位图与说明文字，输入框和按钮被挤出首屏，扫描效率差。
- **B = 9**：首屏自上而下：信任徽标行（Free forever · No signup · No watermark · Private）→ 一句话价值主张 → 副标题 → 左编辑区右控制区，一屏内完成「理解产品 → 输入脚本 → 调参 → Start teleprompter」全部信息；编辑器内置的示例文案同时充当使用说明（空格暂停、方向键调速/调字号），信息密度高且不乱。移动端徽标、标题、编辑器依序堆叠，层级保持完好。
- **C = 7**：标题 → 一句产品定位（VoiceGlide、云同步、团队授权、多平台加粗关键词）→ 双 CTA → 评分/商店徽章，营销漏斗层级清晰；但导航区同时出现「Get Started / Sign In / App Store 徽章 / 二维码」多个入口，动作分散；设备渲染图信息量大但可读性一般（文字被遮挡、镜像）。
- **胜者：B**。

### 3. 交互与流程顺滑度
- **A = 7**：落地即得——首页就是输入框，粘贴脚本 → 点 Start，约 2 步进入提词，路径最短之一；工作流页顶部工具栏图标齐全但图标偏小、无文字标签（仅滑杆有），移动端工具栏折叠成一排小图标 + 下拉箭头，可发现性一般；「新/旧提词器」双入口增加一次不必要的决策。
- **B = 9**：同样落地即输入，且控制面板在开始前就完整可见（速度/字号/倒计时/镜像/对齐/引导线/语音），参数所见即所得；示例文案直接教了快捷键（空格暂停、↑↓调速、←→调字号），运行页全屏无干扰、左侧有阅读引导箭头；桌面与移动工作流一致性好。约 2 步进入提词且学习成本最低。
- **C = 5（依据有限）**：其 web 产品需注册（登录墙），从落地到开始提词至少需要「Get Started → 注册/Google 登录 → 进入应用」3 步以上，明显长于 A/B；首页手机渲染图显示应用内有录制、语音识别、固定速度/定时滚动切换等控件，暗示应用内交互成熟，但无法直接验证工作流可用性，按可证据据实给分。
- **胜者：B**。

### 4. 功能完整度
- **A = 7**：工作流截图可见：暂停/播放、对齐方式、水平镜像、（疑似）垂直翻转、背景色、文字色、字号滑杆（58px）、边距 5%、速度 10、**Record Video 录制**。有录制是亮点；未见倒计时、语音跟随、导入、字数/时长估算。
- **B = 8**：首页控制面板可见：速度（≈140wpm 换算）、字号、倒计时、Mirror H / Mirror V、对齐（Left）、引导线（Guide）、**Voice 语音跟随**、文字色三选、**Import 导入**、字数 + 口播时长估算、本地自动保存。覆盖面最广；未见录制功能。
- **C = 8（依据有限）**：首页明示：**VoiceGlide 语音跟随**（跟声暂停/续读）、云同步脚本、团队授权、iOS/Android/Mac/Web 多端、渲染图中可见录制按钮、语音识别、固定速度/定时滚动、镜像文本（平板渲染图文字为镜像）。宣称功能面最大（多端 + 云 + 团队），但均为首页宣称、无工作流实证。
- **胜者：B 与 C 并列**（B 胜在可见可证，C 胜在宣称广度；A 缺语音/导入/倒计时）。

### 5. 性能实测
- **A = 9**：TTFB 8ms、DCL 52ms、load 74ms，三项全部第一，请求 15 个也不多；接近静态页极限速度。
- **B = 8**：TTFB 31ms、DCL 137ms、load 147ms，请求仅 5 个（最少），绝对值依然很快，仅比 A 慢约一倍但用户不可感。
- **C = 5**：TTFB 60ms、DCL 331ms、load 754ms、47 个请求——load 是 A 的 10 倍、请求数是 B 的 9 倍，与首页大量渲染图/营销资源一致；虽 754ms 绝对值尚可接受，但在同环境对比中明显垫底。
- **胜者：A**。

### 6. 文案与信任感
- **A = 6**：「Free for any use (both commercial and non-commercial)」明确免费授权范围，「no extra software needed」「Bookmark this site」朴实清楚；但文案偏长偏说明书化，无隐私承诺，cookie 横幅 +「AI Script Generator」外链广告位略降专业感，「new/old prompter」暴露内部实现。
- **B = 9**：徽标行一次性给足四个信任信号（Free forever / No signup / No watermark / Private）；「your script never leaves your device」在副标题与编辑器示例中两次强调隐私（本地运行、不上传）；「Autosaved locally — nothing is uploaded」进一步佐证；文案短句、口语化、精准（「Break a leg!」收尾有人味）。三者中信任建设最完整。
- **C = 7**：「studio-grade」「No expensive hardware required」定位清晰，五星 +「from 100K+ reviews」+ 双商店徽章是强社会证明；但「100K+ reviews」无法核验来源，且要求注册/登录（与 A/B 的免登录形成对照），无隐私承诺，信任更多靠背书而非承诺。
- **胜者：B**。

## 总分与总排名
1. **B — 52/60**：六维中五维第一，视觉、信息层级、流程、文案全面领先，性能亦优。
2. **C — 40/60**：营销与功能宣称最强（多端/云/语音跟随），但登录墙拉长流程、性能垫底、工作流不可证。
3. **A — 39/60**：性能最快、路径最短，但视觉与信息组织明显落后一代，信任信号不足。

## 各产品最应改进 Top 3

**A**
1. 首屏重构：压缩说明文字、移除装饰色块，让「输入框 + 单一 Start 按钮」在桌面与 375 移动端都进首屏；合并「new/old prompter」双入口。
2. 视觉体系升级：统一字阶与间距、去掉说明书式长段落、cookie 横幅改为轻量样式。
3. 补齐关键功能与信任信号：倒计时、语音跟随、脚本导入，以及明确的隐私承诺（脚本是否离开设备）。

**B**
1. 增加录制（camera/screen record）能力，补齐与 A/C 的差距。
2. 移动端编辑器区域出现双滚动条与内容裁切（示例文字被截断），需优化小屏布局。
3. 首屏下方补充轻量的社会证明（用户数/评价），目前信任全靠自我承诺。

**C**
1. 降低进入门槛：提供免登录的 web 试用（guest 模式）或至少演示沙盒，缩短落地到提词的步数。
2. 性能优化：首页 47 个请求、load 754ms，应压缩/懒加载设备渲染图与第三方脚本。
3. 首屏渲染图信息可读性：三块设备图相互叠压、文字截断/镜像，建议精简为 1-2 块并保证文字完整可读；「100K+ reviews」注明来源以增强可信度。
